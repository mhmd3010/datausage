Advance Data Usage plugin for PHPNuxBill

Features: 

- uses API, routeros script/scheduler, cron 
- save in DB 
- fetch realtime sessions using api for easy network diagnostics 
- daily usage history ( upto 30days )
- session history upto ( 100 sessions )

Installation:

- copy dataUsage.php to system/plugin directory
- copy data_usage folder to system/plugin/ui directory
- log into admin dashboard and follow plugin instructions from Settings page
